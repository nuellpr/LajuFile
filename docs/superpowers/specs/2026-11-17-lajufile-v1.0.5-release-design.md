# LajuFile v1.0.5 Big Release — Design Spec

**Date:** 2026-11-17  
**Branch:** `feat/hardening-polish` (base `main` @ `3e66c07`)  
**Target Version:** `1.0.5` (`v1.0.5`) — prepared locally on branch without tagging/pushing to GitHub yet.

## Goal
Resolve remaining storage, reliability, supply-chain, updater, proxy, Windows resource/manifest, extension packaging, and version-parity gaps so `v1.0.5` ships as one complete, durable release across Windows, macOS, and Linux without bloated dependencies.

## Approaches Considered
1. **Focused `v1.0.5` Hardening, Reliability & Release Automation (Selected):** Fix every observed bug and release blocker cleanly inside existing crates (`lajufile-core`, `lajufile-app`), add proxy + startup update check + verified `tools.rs` checksums + Windows manifest/version injection + CI/release packaging automation using existing workspace dependencies (`reqwest` + `windows-sys` + in-crate `Sha256`).
2. **Feature-heavy rewrite (`v2.0.0` scheduler + full 86-language machine translation + new crypto crates):** High surface area, risks regressions and large review debt; unnecessary for solving core durability and release blockers.

## Scope & Constraints
- **Zero unnecessary crates (`Ponytail` discipline):** Reuse `windows-sys` (`Win32_Storage_FileSystem`), `reqwest` (`socks` + `native-tls` + `Proxy`), and `lajufile_core::checksum::Sha256`.
- **Storage safety (`download.rs`, `segmented.rs`):**
  - `finalize_temp` keeps no-overwrite semantics (`DestinationExists`) across NTFS, exFAT, and FAT32 via Windows `MoveFileExW(..., 0)` (no `MOVEFILE_REPLACE_EXISTING`, cross-device `create_new` copy fallback) and Unix `hard_link` + `EXDEV`/`Unsupported` `create_new` copy fallback.
  - Check available disk space (`ensure_disk_space`) before allocating/downloading when expected byte size is known (`GetDiskFreeSpaceExW` on Windows, `df -Pk` probe on Unix), returning `DownloadError::InsufficientDiskSpace`.
  - Add bounded automatic retries (`[2s, 5s, 10s]`) on transient single-stream errors via `download_single_with_retry`.
- **Network, Proxy & Identity (`http.rs`, `settings.rs`, `engine.rs`, `dialogs.rs`):**
  - Update `DEFAULT_USER_AGENT` to `LajuFile/<CARGO_PKG_VERSION>`.
  - Add `Settings.proxy_url` (`http`, `https`, `socks4`, `socks4a`, `socks5`, `socks5h`) applied dynamically on startup and `UpdateSettings` save.
- **Non-Windows Cookie Protection (`cookie.rs`, `checksum.rs`):**
  - Replace custom XOR/tag fallback with versioned `"LF2"` envelope using RFC 2104 `HMAC-SHA256` + `SHA-256` CTR stream and constant-time tag verification while keeping Windows DPAPI untouched.
- **Video & Supply-Chain (`engine.rs`, `tools.rs`, `installer.rs`):**
  - Preserve `.m4a` filenames and pass native audio extraction args when an audio-only selector (`ba...` without `bv`) is queued; pass video jobs cleanly without forcing `.m4a.mp4`.
  - Verify `yt-dlp` (`SHA2-256SUMS`), `deno` (`.sha256sum`), Windows `ffmpeg` (`gyan.dev/...sha256`), and Linux `ffmpeg` (`yt-dlp/FFmpeg-Builds` `checksums.sha256`) before extraction/installation.
  - Graceful stop attempt (`taskkill /IM` / `pkill -TERM` + wait) before forced kill in `installer::stop_running_lajufile`.
- **Auto-Update Check & UI (`settings.rs`, `engine.rs`, `app.rs`, `main_window.rs`, `dialogs.rs`, `i18n.rs`):**
  - Add `Settings.auto_check_updates` (default `true`) and `last_update_check_ms` (24h cooldown), running silent background update checks once at startup and rendering a clickable menu-bar pill when a newer release exists.
- **Windows Manifest, Auto-Versioning & Pipelines (`lajufile.manifest`, `lajufile.rc`, `build.rs`, `ci.yml`, `release.yml`, `CHANGELOG.md`):**
  - Embed `asInvoker` + `PerMonitorV2` DPI + `longPathAware` + Common Controls v6 Windows manifest and auto-inject `CARGO_PKG_VERSION_*` integers into `lajufile.rc`.
  - Publish Chromium/Firefox extension zips in `release.yml`, enforce version parity in `ci.yml`, and bump workspace/extension/README/test mock versions to `1.0.5` with `CHANGELOG.md`.

## Non-Goals
- External store submissions (Chrome Web Store, Edge Add-ons, Firefox AMO), SignPath/Apple notarization credentials, download queue scheduler, or full 86-language dictionary expansion.
